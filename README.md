# Prog 1 (EE23A) — Kursmaterial Python

Prov och träningsuppgifter för kursen **Programmering 1** på gymnasienivå.  
Målgrupp: nybörjare på el-programmet, 17 år.

Upplägget är att stegvis gå igenom Python och kontrollera varje avsnitt med ett prov.  
Varje avsnitt har **3 prov** (a/b/c) och **3 träningsfiler** — alternativversionerna har identisk struktur men olika teman, för omprov eller parallella grupper.

## 🧠 Pedagogik

- **Ett moment i taget.** Varje prov fokuserar på ett avgränsat moment. Eleverna ska inte behöva kombinera flera nya koncept samtidigt.
- **Igenkänning via teman.** Uppgifterna använder vardagliga teman (film, mat, djur, spel) för att sänka tröskeln och hålla motivationen uppe.
- **Exempelkörning som kontrakt.** Varje uppgift visar exakt hur programmet ska se ut när det körs.
- **Facit synligt.** Eleverna lär sig genom att jämföra sitt svar med facit.
- **Gradvis svårighetsökning.** Uppgift 1 är alltid enklast. Uppgift 5 kombinerar momentet med tidigare kunskaper. F-strängar används endast i uppgift 5.
- **Alternativversioner (a/b/c).** Identisk struktur, olika tema — möjliggör omprov utan att uppgifter sprids.

## 📐 Provmall

Varje prov har 5 uppgifter. Varje uppgift har alltid tre delar:

```markdown
### Uppgift N: [titel]

**Uppgift:** [instruktion]

**Exempel på körning:**
\```text
[exakt terminalutskrift]
\```

**Facit:**
\```python
[pythonkod]
\```
```

### Progression per avsnitt

| Avsnitt | U1 | U2 | U3 | U4 | U5 |
|---|---|---|---|---|---|
| **K1** | `print()` × 2 | `print()` × 4 | `input()` + `print(..., var)` | 2× `input()` + f-sträng | 3× `input()` + 3× `print(f"...")` |
| **K2** | `if/else` (text) | `if/else` (tal) | `if/elif/else` (3 val) | `if/elif/elif/else` (4 val) | Nästade `if` |
| **K3** | `while True` + `print`, ingen input | `input()` i loop, ingen `break` | `input()` i loop + svar | `break` på nyckelord | Meny med `if/elif/else` + `break` |
| **K4** | Lista med 3 strängar + `print` | Lista med 4 tal + `print` | Blandad lista + `print` | 2× `input()` → lista | `input()` + `int(input())` → lista + f-sträng |
| **K5** | Blandad lista, skriv ut hela | Given lista: hela + `[0]` + `[sista]` | Lista + `input()` → välj element | Lista med tal + `input()` → välj + enhet | Längre lista (4 el.), val 0–3 + f-sträng |
| **K6** | `for x in lista: print(...)` | `for i in range(...)` | `for`-loop + mening per element | `for i in range(...)` + beräkning | `random.choice()` + f-sträng |
| **K7** | `def f()` + anrop × 1 | `def f()` + anrop × 3 | 3 funktioner i ordning | `def f(x)` + argument | `def f(a, b)` + beräkning + f-sträng |
